Install Placekey for Excel

The Placekey Excel Add-in adds a sidebar to Excel that generates Placekey identifiers for rows of addresses. It runs entirely in your browser — no server, no data leaves your machine except the address values sent to the Placekey API.

Download manifest.xml

Install on Excel for Web

  1. Click the Download manifest.xml button above.
  2. Open any Excel workbook at office.com.
  3. On the Home tab of the ribbon, click Add-ins → More Add-ins → the MY ADD-INS tab → Upload My Add-in.
  4. Click Browse, select the downloaded manifest.xml, then Upload.
  5. The Placekey button now appears on the Home ribbon. Click it.
  6. Enter your API key, map columns, click Generate.

Install on Excel for Mac

  1. Click the Download manifest.xml button above.
  2. Open Terminal and paste: 
    mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef
mv ~/Downloads/manifest.xml ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/
xattr -d com.apple.quarantine ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/manifest.xml
    The xattr line strips macOS Gatekeeper's quarantine flag. Browsers stamp every downloaded file with it, and Excel silently ignores quarantined manifests — this is the single most common reason the add-in doesn't show up.
  3. Fully quit Excel with ⌘Q. Closing the workbook window is not enough — a background Excel process caches the wef folder. Then relaunch Excel.
  4. Open any workbook. The Placekey button appears directly on the Home ribbon.
  5. Click it, enter your API key, map columns, click Generate.

If the button doesn't appear: open Home → Add-ins and look under MY ADD-INS for a Shared Folder or Developer Add-ins section. That's also the place to manually enable it if it was installed but not active.

Troubleshooting

  • Mac: add-in doesn't appear after sideload — 99% of the time this is the quarantine flag. Run xattr -l ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/manifest.xml; if you see com.apple.quarantine, remove it with xattr -d com.apple.quarantine <path> and fully quit Excel with ⌘Q before relaunching.
  • Add-in doesn't appear (Web) — reload the browser tab; if still missing, re-upload the manifest through Home → Add-ins → More Add-ins → MY ADD-INS.
  • "This add-in is not trusted" — sideloaded add-ins show this on first load; click Trust it.
  • Updating to a new version — download the latest manifest.xml and re-upload (Web) or re-copy into wef and strip quarantine (Mac). Code updates (JS/HTML) don't require re-sideload — they're fetched from GitHub Pages on each load.
